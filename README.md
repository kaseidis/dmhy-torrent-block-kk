# 动漫花园种子屏蔽助手

面向 [动漫花园](https://share.dmhy.org/) 的本地用户脚本，用于过滤不想看到的发布者或标题，并改善列表页和详情页的阅读体验。

## 功能

- 本地黑名单：按发布者 ID 或标题关键词过滤
- 正则表达式：关键词可使用 `/表达式/` 格式
- 快捷屏蔽：右键发布者名称加入黑名单
- 标题转换：支持原文、简体和繁体显示
- 页面美化：重新整理导航、搜索框和资源列表
- 详情页优化：固定侧栏宽度，正文自适应，并提供移动端单栏布局
- 广告隐藏：隐藏常见广告位和推广元素

## 版本说明

这是增强版脚本的本地维护 fork，专注于本地黑名单、标题转换和动漫花园页面体验优化。配置通过 Tampermonkey 保存在本地。

脚本仍会：

- 从 jsDelivr 加载 OpenCC，用于简繁体转换
- 在需要显示发布者名称时，请求动漫花园同源用户页面

## 安装

1. 安装 Tampermonkey 或兼容的用户脚本管理器。
2. 打开仓库中的 [`dmhy_torrent_block.user.js`](./dmhy_torrent_block.user.js)。
3. 选择 Raw，并确认安装或更新。

## 使用

- 点击页面左下角的“管理种子黑名单”编辑发布者 ID 和关键词。
- 点击“切换标题显示”在原文、简体和繁体之间切换。
- 在资源列表中右键发布者名称，可快速加入黑名单。

发布者 ID 支持纯数字或 `用户名(ID)`；多个条目用分号分隔。

## 开发与检查

脚本保持为单文件用户脚本，不需要构建步骤。提交前可运行：

```bash
node --check dmhy_torrent_block.user.js
```

代码按职责拆分为配置、缓存、黑名单、标题、过滤、界面、广告、页面美化、事件和应用初始化等模块。页面样式分别限定在列表页与详情页作用域中，避免互相影响。
